Coffee shop app icon assets

All files are PNG, square, and exported from the generated 1024x1024 master.

- play-store/icon-512x512.png: Google Play Store listing icon (512x512).
- web/: favicon, Apple touch icon, and PWA icons.
- android/: standard Android launcher icon density sizes.
- ios/AppIcon-1024.png: 1024x1024 App Store source icon.
- master/: original 1024x1024 exported master.

Notes:
- Android adaptive icons can require separate foreground and background layers; these exports are standard square launcher icons.
- iOS projects may generate device-specific icon sizes from the 1024x1024 source using Xcode or the project's asset pipeline.
